# Drisyon Sadhana · AI, RAG & Agentic Systems (50H) Lab Starter

Starter repository for the 50-Hour Applied AI, RAG & Agentic Systems Track.

## How to use:
1. Clone this repo: `git clone <your-fork-url>`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the hard gates: `pytest tests/`
4. Implement the required functions in `src/` until all gates pass green!
